## 📌 About the Project

SwasthiQ Pharmacy CRM is designed to streamline pharmacy workflows by providing a centralized system to manage medicines, monitor stock levels, and track daily sales.

The application focuses on solving practical challenges such as:
- Keeping track of medicine availability
- Avoiding stockouts and overstocking
- Monitoring expiry and low-stock items
- Generating useful business insights from daily sales

---

## ⚙️ System Overview

The project follows a **modern full-stack architecture**:

- **Backend:** High-performance API built using FastAPI
- **Frontend:** Interactive and responsive UI built with React
- **Database:** Lightweight and efficient SQLite storage

The system ensures smooth communication between frontend and backend, delivering a seamless user experience.

---

## 🧠 Smart Logic & Functionality

One of the core strengths of this project is its **automated data consistency system**, which ensures:

- Medicines automatically update their status (Active / Low Stock / Expired / Out of Stock)
- Sales automatically deduct inventory in real time
- Invalid states (like expired items being active) are prevented

This reflects real-world business logic and improves reliability.
